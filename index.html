1단계: 완성된 단일 HTML 파일 다운로드

이 웹앱은 별도 빌드나 백엔드 없이 index.html 파일 단 1개로 완벽히 구동되도록 설계되었습니다.

2
GitHub 새 저장소(Repository) 생성

GitHub 로그인 후 우측 상단 + → New repository를 클릭하고 저장소 이름(예: zero-waste-smart-fridge)을 Public으로 생성합니다.

3
index.html 파일 업로드

Add file → Upload files를 눌러 방금 다운로드한 index.html을 드래그해 넣고 Commit changes를 누릅니다.

4
GitHub Pages 활성화

저장소 상단 Settings → Pages 메뉴로 이동하여 Branch를 main / /(root)로 선택 후 Save를 누르면 약 30초 뒤 라이브 링크가 생성됩니다!
